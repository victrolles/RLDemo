# RLDemo
Come and try RL agent playing video games through real-time inference

The React interface includes a demo gallery and a live inference workspace with game, algorithm, and checkpoint selection, live environment frames, and per-step and total rewards.

See [running live inference](docs/live_inference.md) for setup, checkpoint discovery, the WebSocket protocol, and tests. See [frontend instructions](frontend/README.md) for the React app and GIF gallery.
